Win rate by starting post position, pulled straight from Del Mar's own "Winning Post Positions" page — season-to-date for the current meet, not a single day's read the way Saratoga's Bias Tracker is. The "leans inside/outside" line above the table is a locally-computed, purely statistical read — no AI, no prose to interpret — comparing the aggregate win rate of the inside half of posts against the outside half; it only calls a lean at all once the distance has at least 15 total wins on record, since with fewer than that one early-speed winner can swing a post's win% wildly and produce a confident-sounding but meaningless read. It's a genuinely different kind of signal than the Bias Tracker above (which is Andy Serling's own daily read of a specific card, for Saratoga only), so it's deliberately not shown as one of that table's Dirt Bias/Turf Bias tags — check the starts column before leaning on any single percentage either way.

Pulled live from each track's own entries page (NYRA for Saratoga, DMTC for Del Mar, monmouthpark.com for Monmouth) — post position, jockey, trainer, weight, and (where the source actually publishes them) morning-line and current odds. Not every source has every field: Monmouth, for instance, has a morning-line column but doesn't currently populate it, so it shows blank rather than a guess.
